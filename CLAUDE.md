# ALMASOFT - Instrucciones para Claude

## Antes de realizar cualquier cambio

Lee completamente el archivo **ALMASOFT_MASTER.md**.

No empieces a programar hasta entender el proyecto.

## Reglas obligatorias

- NO crear tablas nuevas.
- NO crear columnas nuevas.
- NO modificar el esquema de la base de datos.
- NO cambiar la arquitectura del proyecto.
- NO renombrar rutas.
- NO renombrar componentes.
- NO romper el panel administrativo.
- Mantener el mismo diseño visual.
- Reutilizar componentes antes de crear otros nuevos.
- No duplicar código.
- Utilizar únicamente la base de datos existente.

## Forma de trabajo

Siempre trabaja por fases.

Antes de modificar archivos importantes:

- Explica qué archivos modificarás.
- Explica por qué.
- Indica el impacto del cambio.

Al finalizar cada fase:

- Ejecuta pruebas.
- Verifica que compile.
- Entrega un informe de cambios.
- Espera autorización antes de continuar.

## Objetivo

Mantener ALMASOFT estable, consistente y reutilizable.
